# ✨ Random Quote Generator

A clean and interactive Random Quote Generator web application built with **Python and Flask**.

The application displays an inspirational quote and its author and allows users to generate a new quote with a single click.

---

## 📌 Project Overview

This project was developed as part of the **CodeAlpha App Development Internship – Task 2: Random Quote Generator**.

The goal of this project is to create a simple and user-friendly application that displays a random quote whenever the application is opened or the user clicks the **New Quote** button.

The application also includes additional features such as copying quotes, saving favorites, dark mode, and responsive design.

---

## 🚀 Features

- 🎲 Random quote generation
- ✨ New Quote button
- ✍️ Displays quote text and author
- 📋 Copy quote to clipboard
- ❤️ Add and remove favorite quotes
- 🌙 Dark Mode
- 💾 Favorites and theme preference saved using browser Local Storage
- 📱 Responsive design for mobile devices
- 🎨 Clean and modern user interface
